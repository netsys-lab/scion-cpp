Generated Vitis Networking P4 Driver
====================================

Build the drivers generated by Vitis Networking P4 here and place the contents of the resulting
`install` directory here. Rename `include` to `vitis_net_p4`.

Building Vitis P4 Drivers
--------------------------

Vitis Networking P4 generates a driver source tree during synthesis. Since we are using multiple
Vitis P4 instances, four drivers are generated. The drivers have to be merged into one source tree
before building. Most files will be identical between the drivers except definitions in
`vitis_net_p4_*_defs.h` and `vitis_net_p4_*_defs.c`.

Create a temporary build directory and place the driver(s) generated by Vitis Networking P4 there.
Assuming the Vivado build directory is `$build_dir`, you can copy and merge the driver code with
```bash
mkdir build
source_dir=$build_dir/open_nic_shell/open_nic_shell.gen/sources_1/ip
cp -r $source_dir/vitis_net_p4_0/src/sw/drivers/* build/
cp $source_dir/vitis_net_p4_1/src/sw/drivers/target/inc/vitis_net_p4_*_defs.h build/target/inc
cp $source_dir/vitis_net_p4_1/src/sw/drivers/target/src/vitis_net_p4_*_defs.c build/target/src
cp $source_dir/vitis_net_p4_2/src/sw/drivers/target/inc/vitis_net_p4_*_defs.h build/target/inc
cp $source_dir/vitis_net_p4_2/src/sw/drivers/target/src/vitis_net_p4_*_defs.c build/target/src
```

The resulting source tree should look like this:
```
build
├── cam_obf
│   ├── inc
│   │   ├── bcam.h
│   │   ├── bf.h
│   │   ├── cam.h

│   └── src
│       ├── bf.c
│       └── cam_obf.c
├── cam_top
│   ├── inc
│   │   ├── cam_top.h
│   │   └── tiny_cam.h
│   └── src
│       ├── cam_priv.h
│       ├── cam_top.c
│       └── tiny_cam.c
├── common
│   ├── inc
│   │   └── vitisnetp4_common.h
│   └── src
│       └── vitisnetp4_common.c
├── counter
│   ├── inc
│   │   └── counter_extern.h
│   └── src
│       └── counter_extern.c
├── Makefile
├── table
│   ├── inc
│   │   └── vitisnetp4_table.h
│   └── src
│       └── vitisnetp4_table.c
├── target
│   ├── examples
│   │   ├── ctrl_example.c
│   │   ├── five_tuple_example.c
│   │   └── interrupt_example.c
│   ├── inc
│   │   ├── vitis_net_p4_0_defs.h
│   │   ├── vitis_net_p4_1_defs.h
│   │   ├── vitis_net_p4_2_defs.h
│   │   ├── vitis_net_p4_3_defs.h

│   └── src
│       ├── vitis_net_p4_0_defs.c
│       ├── vitis_net_p4_1_defs.c
│       ├── vitis_net_p4_2_defs.c
│       ├── vitis_net_p4_3_defs.c

│   │   └── vitisnetp4_target_mgmt.h

├── x86.mak
└── xilinx_vitisnetp4_drivers.mak
```

Build the driver with `make -C build`. This should create a directory `build/install`. Copy its
contents into this directory:
```bash
cp -r build/install/include ./vitis_net_p4
cp -r build/install/lib ./lib
rm -r build
```

The resulting structure should look like this:
```
vitis-p4-driver/
├── lib
│   ├── libvitisnetp4drv.a
│   └── libvitisnetp4drv.so
└── vitis_net_p4
    ├── bcam.h
    ├── bf.h
    ├── cam.h
    ├── cam_top.h
    ├── counter_extern.h
    ├── stcam.h
    ├── tcam.h
    ├── tiny_cam.h
    ├── vitis_net_p4_0_defs.h
    ├── vitis_net_p4_1_defs.h
    ├── vitis_net_p4_2_defs.h
    ├── vitis_net_p4_3_defs.h
    ├── vitisnetp4_common.h
    ├── vitisnetp4_table.h
    ├── vitisnetp4_target.h
    └── vitisnetp4_target_mgmt.h
```
